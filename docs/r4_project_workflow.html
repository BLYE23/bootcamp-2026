.Rproj

  • This file gets created when you start a new R project
  • What is an R project?
    • A folder with R code for a particular app or analysis project that is self-contained (can share with anyone)
  • Advantages
    • It automatically sets your working directory so no setwd() is needed
    • Environment variables and functions can be shared across scripts

DEMO: Start an R Project

  • Click New Project button >> New Directory >> New Project
  • Name: my-project
  • Subdirectory: ~/Desktop

data

  • The data folder contains all the data for your project
  • raw/ is never touched by hand — treat it as read-only
  • processed/ starts empty — and then everything in it is generated by an R script

DEMO: Create a data folder

  • Create a data folder in your my-project folder
  • Create a subfolder called raw
    • Copy over the gapminder.csv and country_attributes.csv files
  • Create a subfolder called processed

scripts

  • The scripts folder contains all the R scripts for your project
  • They are often numbered so the run order is visible:
    • 1_clean.R
    • 2_transform.R
    • 3_plot.R
  • Why are they separated out into many scripts?
    • Each one does exactly one job, which makes it easier to debug and maintain

Step 1a: Fix Whitespace

  • " Chile" and "Japan " have leading and trailing spaces
    • They are currently invisible but will break future joins
  • str_trim() removes them
  • str_to_title() fixes stray casing like "germany" or "FRANCE"

EXERCISE: Trim & Standardize Case

  • Within your R script, create a new dataframe (tibble) called formatted
    • Trim the whitespace in the country column
    • Then title-case it


  • Hint: Remember dplyr!

SOLUTION: Trim & Standardize Case

formatted <- raw |>
  mutate(
    country = str_trim(country),
    country = str_to_title(country)
  )

Step 1b: Fix Typos & Alt Names

  • Whitespace / case fixes are mechanical — no knowledge is required
  • This part isn’t: "Usa" and "Brasil" need someone who knows these should be "United States" and "Brazil"
  • case_when() is the function for one-to-one substitutions


  • Question: How would you find these errors?
    • Things break down the line!

EXERCISE: Map the Known Typos

  • Within your R script, create a new dataframe called clean_names
    • map "Usa" to "United States"
    • map "Brasil" to "Brazil"
    • leave everything else unchanged


  • Hint: look up ?case_when to see syntax examples

SOLUTION: Map the Known Typos

clean_names <- formatted |>
  mutate(
    country = case_when(
      country == "Usa"    ~ "United States",
      country == "Brasil" ~ "Brazil",
      .default = country
    )
  )

Step 1c: Duplicates

  • Duplicates should be removed to avoid double counting values
  • Use the distinct() function to remove duplicate values
clean_names |> filter(country == "Canada")

R Project Steps

  1. Create an R project (.Rproj)
  2. Paste in the raw data (raw folder)
  3. Write R scripts to analyze the data (scripts folder)
  4. Reference helper functions within the R scripts (R folder)
  5. Create a notebook to document the results (.Rmd file)
  6. Create a simple script to run all the other scripts (.R file)

Final Thought

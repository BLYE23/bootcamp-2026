Tibbles

  • A tibble is the tidyverse’s version of a data frame
    • Inspired by tbl_df
  • Behaves like a data frame, with a few upgrades:
    • Nicer printing
    • No partial matching
    • Never changes variable names or types on you
  • Create one with tibble() or convert with as_tibble()

Data Frames vs Tibbles

Tidyverse History

  • 1991 (35 years ago): R was created by researchers at University of Auckland in New Zealand
  • 2005 (21 years ago): Hadley Wickham came into the scene by creating data science tools in R
    • ggplot2: grammar of graphics (formerly ggplot)
    • dplyr: grammar of data manipulation (formerly plyr)
  • 2016 (10 years ago): Wickham announced the tidyverse, which helped bring multiple libraries together

dplyr Overview

  • dplyr stands for dataframe pliers
    • Its core verbs are inspired by SQL clauses (select, etc.)
    • Additional functions are often updated or added to the library every few years
  • dplyr uses the pipe syntax (%>%) from the magrittr library
    • Inspired by Magritte’s painting “ceci n’est pas une pipe”
    • In 2021, base R introduced the |> pipe syntax
  • These are dplyr's two core features – verbs and pipes

select()

  • select() picks columns by name
  • df |> select(col1, col2, col3)

mutate()

  • mutate() adds or changes a column
    • df |> mutate(col3 = col1 * col2)
    • df |> mutate(col1 = round(col1))
  • Everything in dplyr executes sequentially
    • So you can reference a column you just created within the same mutate() call

summarize()

  • summarize() collapses a column down to a single summary value
  • df |> summarize(avg_col1 = mean(col1))
  • Only returns the summary — everything else is dropped

EXERCISE: summarize()

  • Find the mean and median population across the whole dataset

SOLUTION: summarize()

df |> summarize(avg_pop = mean(pop),
                med_pop = median(pop))
# A tibble: 1 × 2

group_by() + summarize()

  • group_by() splits your data into groups behind the scenes
  • summarize() then runs separately for each group
  • df |> group_by(col1) |> summarize(avg_col2 = mean(col2))

EXERCISE: group_by() + summarize()

More dplyr Functions

  • dplyr has many more functions beyond verbs and pipes
    • count, distinct, etc. – basic calculations
    • case_when – conditional logic
    • .by – newer, simpler group by syntax created in 2023
    • join – we’ll be covering in the next session
    • … and much more
  • Just memorize the core dplyr verb and pipe syntax
    • For all other data manipulation tasks – know what’s possible and have AI help with syntax

Note: Functions with the Same Name

  • Some function names exist in multiple packages (e.g. filter())
  • R uses whichever package was loaded most recently
  • Use package::function() to be explicit: dplyr::filter()

lubridate: Working with Dates

  • Not created by Wickham, but he advised the project
  • Dates are notoriously hard to work with in base R
  • lubridate makes dates and times easier to parse and manipulate
    • ymd(), mdy(), dmy(), etc. parse dates from text
    • year(), month(), day(), etc. extracts the date parts
    • Includes many other datetime capabilities like adding / subtracting dates, specifying time intervals, etc.

lubridate: Working with Dates

Without lubridate, this will return an error:

detach("package:lubridate", unload = TRUE)
year("09/15/2026")


With lubridate, the character date can be easily parsed:

library(lubridate)
mdy("09/15/2026")
[1] "2026-09-15"
year(mdy("09/15/2026"))
[1] 2026
